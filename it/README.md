# Italian Source Texts and Scene Breakdowns

This directory holds the Italian source text of Dante's *Divina Commedia*,
split canto by canto under `inferno/`, `purgatorio/`, and `paradiso/`, along
with scene-by-scene breakdowns of each canticle.

## Scene breakdowns

The files `inferno-ja.md`, `purgatorio-ja.md`, and `paradiso-ja.md` under
`ref/` summarize each canticle as a sequence of scenes. For every canto they
provide a `## Canto N` heading followed by a Markdown table with the columns
`行` (line range), `場面名` (scene name), and `内容` (a one-sentence summary of
what happens). The summaries are written in Japanese.

These breakdowns were generated by GitHub Copilot (GPT-5.4) from the canto
source files, following the policy in [`AGENTS.md`](ref/AGENTS.md). Per that
policy, cantos were processed one at a time, scenes were divided at natural
changes in the text (aiming for roughly 30 lines per scene without forcing the
length), and scene names were chosen as short, concrete labels for the
dominant event of each passage.
